📖 Guia Rápido de Pré-Requisitos para Projeto Lógico (Cheat Sheet)

1. Notação Tradicional 1:N vs. (min, max)

  • Tradicional: 1 fica no lado do "um" e N no lado do "muitos".
  • (min, max): Fica na própria entidade. Ex: Empregado (1, 1) e Departamento (4, N). Lados se invertem!
  • Participação Parcial: min = 0 (linha simples).
  • Participação Total: min >= 1 (linha dupla).

2. Hierarquias EER (d/o, Total/Parcial)

  • 'd' (Disjunta): Subclasses mutuamente exclusivas (interseção vazia: π(A) ∩ π(B) = ∅).
  • 'o' (Sobreposta): Pode pertencer a mais de uma subclasse simultaneamente.
  • Total (Linha Dupla): União cobre toda a superclasse (π(A) ∪ π(B) = π(Super)).
  • Parcial (Linha Simples): Pode não ser de nenhuma subclasse.

3. RIR e Políticas de Remoção (b, p, n)

  • b (Bloqueio / RESTRICT): Rejeita o DELETE se houver tuplas filhas (ex: empregados no departamento).
  • p (Propagação / CASCADE): Apaga em cascata (obrigatório para entidades fracas, multivalorados e tabelas M:N).
  • n (Nulos / SET NULL): Seta a FK para NULL (ex: chefe demitido em SUPERSSN).

4. SQL-92 CREATE ASSERTION

CREATE ASSERTION <nome>
CHECK (NOT EXISTS (
    SELECT * FROM ... WHERE <condicao_violadora>
));

Usada para regras globais entre múltiplas tabelas (ex: nenhum funcionário ganha mais que o gerente do depto).
